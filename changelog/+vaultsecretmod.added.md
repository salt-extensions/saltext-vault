Added `vault_secret` execution and wrapper modules. They contain pre-existing logic refactored into a separate module. Note that the positional argument order of {py:func}`vault.read_secret <saltext.vault.modules.vault.read_secret>` has changed slightly in {py:func}`vault_secret.read <saltext.vault.modules.vault_secret.read>`: `default` moved before `metadata` and `metadata`/`version` became keyword-only arguments. {py:func}`vault.list_secrets <saltext.vault.modules.vault.list_secrets>` lost the `keys_only` parameter in {py:func}`vault_secret.list <saltext.vault.modules.vault_secret.list_>`. The new functions do not swallow any kind of exception and thus don't return `False` when they face one. {py:func}`vault_secret.read <saltext.vault.modules.vault_secret.read>` and {py:func}`vault_secret.list <saltext.vault.modules.vault_secret.list_>` only return their `default` argument for select API errors, making the behavior more predictable.
